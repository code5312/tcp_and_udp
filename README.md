# TCP & UDP 소켓 매칭 서버

게임 서버 개발을 목표로, C++ 저수준 소켓 프로그래밍을 처음부터 단계적으로 학습하기 위한 프로젝트입니다. "여러 클라이언트를 동시에 받아서 둘씩 짝지어주고(matching), 짝지어진 사이의 메시지를 서로에게 전달(relay)하는 서버"라는, 실시간 대전 게임(1:1 매칭 게임, 턴제 게임 등) 서버의 가장 기본적인 뼈대를 TCP와 UDP 양쪽으로 각각 구현하면서 두 프로토콜의 차이를 직접 부딪혀보는 것이 목적입니다.

## 왜 TCP와 UDP를 둘 다 구현했는가

게임 서버에서는 보통 두 프로토콜을 용도에 따라 나눠 씁니다 — 매칭/로그인/채팅처럼 순서와 신뢰성이 중요한 것은 TCP, 캐릭터 위치/입력처럼 최신 값만 중요하고 지연에 민감한 것은 UDP. 이 차이를 글로만 아는 것과, 같은 기능을 두 프로토콜로 각각 구현하면서 "왜 TCP엔 필요한 게 UDP엔 없고, UDP엔 필요한 게 TCP엔 없는지"를 직접 겪어보는 것은 다르다고 판단해서, 의도적으로 같은 매칭/relay 로직을 두 번 만들었습니다.

## 무엇을 배우고 확인했는가 (요약)

자세한 과정과 발견한 버그, 그 원인과 해결 과정은 각 디렉토리의 `LEARNING_NOTES.md`에 단계별로 기록되어 있습니다. 여기서는 핵심만 요약합니다.

### TCP (`TCP_socket_mini/`)
- **I/O 멀티플렉싱**: `select()`와 `epoll()`로 여러 클라이언트를 동시에 처리하는 두 가지 방식을 나란히 구현해서 직접 비교.
- **매칭 대기열**: 대기자를 변수 하나가 아니라 큐로 관리해야 하는 이유(재대기 경로가 생기면 단일 변수로는 대기자가 유실됨)를 버그를 직접 겪고 고치며 확인.
- **Non-blocking I/O + 쓰기 버퍼링**: 느린 클라이언트 하나가 `write()` 블로킹으로 서버 전체를 멈추는 head-of-line blocking 문제를, non-blocking 소켓 + fd별 송신 버퍼(outbox) + `EAGAIN`/`EPOLLOUT` 처리로 해결.
- **메시지 프레이밍**: TCP는 스트림이라 메시지 경계를 보장하지 않는다는 것을, 개행(`\n`) 기준 재조립 버퍼(inbox)를 직접 만들며 확인.
- **동시성 버그들**: 여러 클라이언트가 같은 처리 배치(같은 `select()`/`epoll_wait()` 호출) 안에서 동시에 끊길 때 생기는 "유령 매칭"(끊긴 클라이언트가 대기 중이던 제3자와 순간적으로 매칭됐다가 곧바로 풀리는 버그)을 여러 경로에서 발견하고 수정 — 반복적인 코드 리뷰(`/code-review`)를 통해 발견한 실제 동시성 버그들.

### UDP (`UDP_project/`)
- **연결이라는 개념이 없음**: `accept()`가 없고, 클라이언트를 fd가 아니라 `(IP, 포트)` 주소로 식별.
- **프레이밍이 필요 없음**: datagram 단위 전송이라 TCP처럼 메시지가 잘리거나 합쳐지는 문제가 없음(TCP와 정반대 지점).
- **연결 종료 신호가 없음**: `read()==0` 같은 신호가 없어서, 클라이언트가 나간 것을 서버가 스스로 판단해야 함 → 유휴 타임아웃(`select()`의 timeout 인자를 처음 실질적으로 사용) + 클라이언트 쪽 주기적 하트비트로 해결. 하트비트가 없으면 "가만히 상대 턴을 기다리는 것뿐인" 멀쩡한 클라이언트도 쫓겨난다는 걸 실제로 재현하며 확인.

## 빌드 & 실행

Linux 전용 헤더(`sys/epoll.h` 등)를 쓰기 때문에 Linux(또는 WSL)에서 빌드해야 합니다.

```bash
# TCP
cd TCP_socket_mini
g++ -std=c++17 -o server server.cpp
g++ -std=c++17 -o server_epoll server_epoll.cpp
g++ -std=c++17 -o client client.cpp
./server        # 또는 ./server_epoll
./client         # 다른 터미널에서 여러 개 실행해서 매칭/relay 확인

# UDP
cd UDP_project
g++ -std=c++17 -o udp_server udp_server.cpp
g++ -std=c++17 -o udp_client udp_client.cpp
./udp_server
./udp_client
```
